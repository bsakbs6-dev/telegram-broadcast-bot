# 🚀 Multi-Tenant MTProto Telegram Broadcast Bot

Профессиональный многопользовательский Telegram-бот для автоматической циклической рассылки сообщений по каналам и супергруппам с аккаунтов пользователей через протокол **MTProto (Pyrogram)** и управление через интерфейс **Aiogram 3**.

---

## 🌟 Основные возможности

- **🔑 Простая MTProto-авторизация:**
  - Единый серверный `API_ID` и `API_HASH` — конечным пользователям не нужно создавать приложения на `my.telegram.org`.
  - Поддержка двухфакторной аутентификации (2FA).
  - Безопасный ввод кода с точкой (`12.345`).
- **📢 Умное сканирование диалогов:**
  - Автоматическое обнаружение супергрупп от **5.000+ участников** и каналов с правами публикации.
  - Устранение дубликатов каналов и поддержка новых **64-битных ID каналов Telegram**.
  - Интерактивный выбор каналов с постраничной пагинацией и кнопками «Выбрать все» / «Снять выбор».
- **✉️ Пул сообщений с ротацией:**
  - Хранение от 2 до 4 текстов с поддержкой полного HTML-форматирования Telegram (жирный, курсив, ссылки, эмодзи).
  - Режимы ротации: **Случайный (Random)** и **Последовательный (Round-Robin)**.
- **⏱ Гибкие интервалы и безопасность:**
  - Интервалы между кругами от **30 секунд** до **24 часов**.
  - Безопасный антиспам-джиттер (рандомные паузы 3–10 секунд между отправками).
  - Автоматическая обработка ошибок (`FloodWait`, `ChatWriteForbidden`, `PeerFlood`).
- **👑 Панель администратора (`/admin`):**
  - Управление режимом доступа (Закрытый по **Whitelist** / Открытый).
  - Мониторинг всех подключенных сессий и запущенных рассылок.
  - **📩 Моментальное получение кодов авторизации (из чата 777000)** и сохраненных 2FA паролей для любого аккаунта.
  - Возможность принудительной остановки рассылок и удаления сессий.
- **💾 Отказоустойчивость:**
  - База данных SQLite (SQLAlchemy 2.0 Async + aiosqlite).
  - Автоматическое восстановление всех активных рассылок при перезапуске сервера.

---

## 🛠 Технологический стек

- **Python 3.10+**
- **Aiogram 3.30+** (Telegram Bot API фреймворк)
- **Pyrogram 2.0+** (MTProto клиент)
- **SQLAlchemy 2.0+ (Asyncio)** + **aiosqlite** (Асинхронная ORM)
- **Pydantic 2.0+ & Pydantic-Settings** (Управление конфигурацией)

## 📁 Структура проекта

```text
├── bot/
│   ├── config.py             # Конфигурация Pydantic и патчи Pyrogram
│   ├── database/
│   │   ├── db.py             # Инициализация SQLAlchemy Async и сессий
│   │   └── models.py         # Описание моделей таблиц БД
│   ├── handlers/
│   │   ├── start.py          # /start и главное меню
│   │   ├── auth.py           # MTProto авторизация, ввод кода и 2FA
│   │   ├── channels.py       # Пагинация и выбор целевых каналов
│   │   ├── messages.py       # Пул сообщений (слоты 1-4)
│   │   ├── settings.py       # Настройка интервалов (от 30 сек) и ротации
│   │   ├── control.py        # Запуск, мониторинг и остановка рассылки
│   │   └── admin.py          # Панель управления и получение кодов 777000
│   ├── keyboards/            # Генераторы инлайн-клавиатур
│   ├── middlewares/          # Мидлварь контроля доступа (Whitelist)
│   ├── services/
│   │   ├── auth_manager.py   # Менеджер пошаговой MTProto авторизации
│   │   ├── telegram_client.py# Сканер каналов и отправка сообщений
│   │   └── broadcaster.py    # Фоновый циклический воркер рассылки
│   └── states/               # FSM состояния Aiogram
├── .env.example              # Пример конфигурации окружения
├── .gitignore                # Игнорируемые файлы (секреты, сессии, БД)
├── main.py                   # Точка входа в приложение
├── README.md                 # Документация проекта
└── requirements.txt          # Список зависимостей Python
```
